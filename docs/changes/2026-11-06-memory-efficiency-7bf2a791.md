# 降低 Codex 长会话的内存分配与持有

内部员工的长会话输入达到约 112MiB，原服务器多次出现内存耗尽和持续换页。采样将主要分配定位到逐条元数据清理与重复解码；回归实验还确认，短模型名和异步计量任务会延长完整请求的存活时间。

本次沿现有请求链路调整字节与字符串的拥有权，把元数据清理和压缩标记整理改为按项读取、集中合成。内容审计队列改存任务引用，保留既有容量和行为。功能、API 与数据库、Redis 契约继续沿用原版本。

112MiB 图片和 50 条历史元数据的清理测试中，累计分配由约 5.99GB 降至约 117MB，耗时由 1.734 秒降至约 0.142 秒。详细机制、验证方式与替换步骤见[内存优化说明](../operations/memory-efficiency.md)。上线制品与实测记录在交付阶段补充至该说明。
